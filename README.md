# Java 基础练习小程序集
✨ 个人Java学习笔记 + 基础算法 + 实用小工具合集，适合Java初学者学习参考

## 项目简介
本仓库收录了Java基础语法练习、常用算法实现、实用工具类、趣味小案例等小程序，覆盖Java入门核心知识点，代码简洁易懂，可直接运行学习。

## 运行方式
1. 确保本地安装了 Java 开发环境（JDK 8+）
2. 编译对应文件：`javac 文件名.java`
3. 运行程序：`java 文件名`
